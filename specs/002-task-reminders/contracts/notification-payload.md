# Contract: Notification payload, channel and sound

**Feature**: `002-task-reminders`

## Id

```
notificationId(key) = (fnv1a32(key) & 0x7fffffff) || 1
key = `${taskId}:${date}`
```

Deterministic across runs; tested for range and stability.

## Title and body

| Part | Rule | Examples |
|------|------|----------|
| title | occurrence title, untouched | `Read book` |
| body line 1 | `In {lead} · {time}` where `{lead}` = `5 minutes`, `15 minutes`, `30 minutes`, `45 minutes`, `1 hour`; `{time}` = `formatTimeLabel` | `In 15 minutes · 3 PM` |
| body line 2 (optional) | first ≤ 3 sub-item texts joined by ` · `; if more exist, append ` …` | `Chapter 4 · Take notes` |

`formatReminderBody(minutes, time, subItems): string` joins lines with `\n`.

## Plugin mapping (Android and web)

```ts
{
  id,
  title,
  body,
  schedule: { at: fireAt, allowWhileIdle: true },
  channelId: 'reminders',          // Android
  extra: { taskId, date },
  smallIcon: 'ic_stat_reminder',   // Android drawable added under res/drawable (monochrome)
  sound: 'mellow_chime.wav',       // honoured on Android < 8 only; channel carries it otherwise
}
```

## Channel (Android 8+)

| Field | Value |
|-------|-------|
| `id` | `reminders` |
| `name` | `Task reminders` |
| `description` | `Reminders before your tasks are due` |
| `importance` | `4` (HIGH: heads-up + sound) |
| `sound` | `mellow_chime.wav` (file in `res/raw/`) |
| `vibration` | `true` |
| `visibility` | `1` (public) |

Created once at startup by `ensureChannel()`. Android freezes a channel's sound after
creation: to change the sound in a later release, introduce `reminders-v2`, point new
notifications at it and delete `reminders`.

## Sound asset

- Generated by `scripts/generate-chime.py` (Python 3 standard library only).
- Two sine tones, C5 (523.25 Hz) then G5 (783.99 Hz) starting 0.35 s later, each with a faint
  octave harmonic at −18 dB, 12 ms attack, exponential decay (τ ≈ 0.45 s), total 1.4 s,
  44.1 kHz, 16-bit mono, peak −6 dBFS, 20 ms fade-out.
- Written to `android/app/src/main/res/raw/mellow_chime.wav` and
  `public/sounds/mellow_chime.wav`; both copies are committed.
- Web: when `onFiredInForeground` reports a reminder while the tab is open, play
  `/sounds/mellow_chime.wav` through an `Audio` element, respecting a `muted` state if the
  browser blocks autoplay.

## Tap handling

`localNotificationActionPerformed` → `extra` → `navigate('/')` then
`openTaskDetail({ taskId, date })`. If the occurrence no longer exists, Today is shown without
a dialog. The listener is registered in `AppShell` on mount; Capacitor delivers a retained
launch event to it on cold start.
